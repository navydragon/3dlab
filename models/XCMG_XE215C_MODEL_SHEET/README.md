# XCMG XE215C — MODEL SHEET pack

Строго отобранный набор для 3D-моделинга XE215C.

## Главное

- `MODEL_SHEET.md` — что моделировать по каждому из 10 референсов.
- `gallery.html` — удобная визуальная доска; изображения подгружаются с исходных сайтов.
- `selected_refs.csv` — список выбранных референсов.
- `blockout_dimensions.csv` — числа master-конфигурации.
- `links/` — отдельные `.url` ярлыки.
- `download_selected.py` — best-effort скачивание 10 фото + master PDF на твоём компьютере.

## Master-конфигурация

China Machine / XCMG: 21 900 kg, 128.5 kW, boom 5680 mm, arm 2910 mm; габаритный лист даёт 9625 × 2990 × 3100 mm.

Важно: XE215C существует в разных годах/рынках. Более старые листы могут давать, например, 9525 × 2990 × 3000 mm. Не усредняй эти числа.
